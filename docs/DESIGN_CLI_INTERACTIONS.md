## 三、生成主循环：默认视图

### 3.1 启动阶段（~30-60s，LLM 生成 bible + outline）

```
  ╔══════════════════════════════════════════════════════════════════╗
  ║  逆魂纪 · 全自动小说生成                                         ║
  ║  主题: 玄幻  ·  目标: 40 章  ·  模型: deepseek-chat              ║
  ╚══════════════════════════════════════════════════════════════════╝

  📋 正在生成叙事圣经 (Bible) …                             0.002元
     ├── ✅ 世界观设定 (九州碎裂，十二仙脉…)
     ├── ✅ 角色设计 (沈言、几残魂、蒋阶、林玥…共 8 位)
     └── 🔄 章节大纲  32/40 章已规划                        0.004元

  大纲补全完成！共 40 章。按 Enter 开始逐章生成…
```

**细节**：Bible 生成拆成 2-3 次 LLM 调用，每次在终端显示进度。不是一次黑盒等待。失败时不退——重试最多 2 次。如果大纲已有（resume），跳过此阶段。

### 3.2 生成中（核心循环）

```

  ─ 正在生成 第 12 章《外宗来使》 ─────────────────────────────

  沈言站在柴门断剑的废墟前，望着远处天代宗使者的旗帜越来越近。
  他的手不自觉地握紧了剑柄。几残魂的声音在脑海深处回荡——

  "那不是他们欠我的。是我欠他们的。"

  他松开了手。不是放弃——是改变主意。他需要那些使者活着回去，
  把柴门发生的一切带回天代宗。

  天代宗押使踏入柴门前的一刻，沈言注意到蒋阶的表情——门主也在等
  这一刻的到来。两人目光交汇，各怀心思地同时收回了视线。

  ──────────────────────────────────────────────────────────────────

  ──────────────────────────────────────────────────────────────────

  p 暂停  c 取消  1-4 切换面板  Ctrl+K 指令  q 退出(自动保存)
```

**细节**：
- 正文区域每 2s 刷新，显示最新章节的**尾 300 字**（不是从头显示，是滚动到最新位置）
- 如果是 revise 轮次，正文区域显示 `[修订中，第 N 轮]` 而不是新正文
- 质量评分只在章完成后显示（draft 后显示首次评分，revise 后显示最终评分）
- 轮次 `0/2` 表示本版一次通过，未触发自修
- 进度条颜色：running=蓝，paused=黄，needs_review=橙，completed=绿

## 四、4 个面板详细规格

### 4.1 热键总表

| 键 | 动作 | 上下文 |
|---|---|---|
| `1` `2` `3` `4` | 全部/大纲/角色/用量 | 任意 |
| `Ctrl+K` | 指令面板 | 任意 |
| `Esc` | 关闭面板/弹窗 | 面板打开时 |
| `p` | 暂停/恢复 | running |
| `c` | 取消（确认后保存） | running / paused |
| `Enter` | needs_review 时默认重试 | needs_review |
| `↑↓` | 滚动/历史指令 | 面板内 |
| `q` | 退出（生成中: 确认保存后退出）| 任意 |

已删除的旧键：`r`(重试) `s`(跳过) `o`(大纲) `u`(用量) — 统一由指令面板 + 数字键处理。

## 七、恢复流程 (`--resume`)

```bash
$ npm run auto:new -- --resume ./output/逆魂纪
```

加载 `./output/逆魂纪/` 下所有文件 → 读 `progress.json` → 如果 status 为 `paused` / `needs_review` / `running`（上次崩溃）→ 打开 Ink 面板 → 从 `progress.current + 1` 章继续。

**恢复时的特殊处理**：
- 如果最新章节 `.md` 文件存在但内容为空或只有几百字（写作中崩溃），删除该章、重新生成
- 如果 `progress.status === "running"`（异常退出），先检查最新章是否完整（字数 > 500），完整则标记为 done 继续下一章
