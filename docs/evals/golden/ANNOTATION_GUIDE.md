# 黄金集人工打分指南

这份指南统一标注口径，让不同标注者（或你在不同时间）给出的分数尽量一致。读完后，你应该能对任意一个样本的 8 个维度给出可复现的分数。

## 一条最重要的原则

**你是在以读者身份评价文本本身，不是在猜评分器会打几分。**

黄金集的全部价值，在于提供一个**独立于评分器**的裁判。如果你按评分器的规则（数因果连接词、查 AI 高频词）去打分，那它就退化成了评分器的复印件，校验也就失去了意义。所以：

- 凭你作为读者的真实感受打分。
- 不要去想"评分器会怎么算"。
- 哪怕你的分数和评分器差很多，也照实填——那个差距正是我们要发现的东西。

## 打分尺度（所有维度 0-10）

| 分段 | 含义 |
|:----:|------|
| 9-10 | 优秀。这一维度几乎挑不出毛病，达到可出版水准。 |
| 7-8 | 良好。基本没问题，偶有小瑕疵，不影响阅读。 |
| 5-6 | 及格。能读，但这一维度明显有短板，会让你出戏一两次。 |
| 3-4 | 偏弱。问题频繁，影响阅读体验，需要明显修改。 |
| 0-2 | 差。这一维度基本失效，几乎每段都有问题。 |

打分时先判断落在哪个分段，再在段内微调。**整数即可，不必纠结小数。**

## 一个前提：这是「滑窗」不是「整本」

每个样本是连续的 3 章（一个评分滑窗）。你评的是**这 3 章作为一个整体**读起来如何，而不是单章、也不是整本书。开篇章节本就承担铺垫职责，不要因为"还没进入高潮"而扣分。

## 八个维度怎么打

### 1. continuity 连续性

**问的是：这 3 章读起来是不是一个连贯的整体，而不是三段拼接？**

- 后一章有没有承接前一章的人物、地点、线索、物件？
- 上一章的结果有没有影响这一章的行动？
- 高分：章与章之间有清晰的承接桥（同一个物件、未解的悬念、上章的后果）。
- 低分：每章像是各写各的，换个顺序读也没区别。

### 2. logic 因果逻辑

**问的是：人物的行动能不能让你读懂"为什么这么做""这么做换来了什么"？**

- 关键行动有没有动机？有没有"目标 → 阻碍 → 行动 → 结果"的链条？
- 注意：好的中文小说常用**省略和留白**表达因果，不一定有"因为/所以"。**只要你作为读者能推断出因果，就算逻辑通顺**，不要因为它没明说而扣分。
- 高分：每个转折你都跟得上，没有"他突然就……"的跳脱。
- 低分：事件堆在一起，读不出人物为什么行动，或结果莫名其妙。

> 这一维度评分器目前偏严（依赖显式连接词），最容易和人工分拉开差距——请尤其按真实体感打。

### 3. character_consistency 人物一致性

**问的是：人物的行为符不符合他自己的性格和动机？**

- 主角做的事，和他的目标、性格、当前处境一致吗？
- 有没有"为了推进剧情而让人物突然变一个人"？
- 高分：人物的每个选择都像"这个人会做的事"。
- 低分：人物行为前后矛盾，或只是被剧情拖着走、没有自己的意志。

### 4. plot_progress 剧情推进

**问的是：这 3 章有没有实质推进，而不是原地打转或只铺氛围？**

- 每章是否带来可记录的变化：新线索、关系变化、位置变化、道具归属、敌人反应等？
- 高分：读完这 3 章，故事明显往前走了，你想知道接下来。
- 低分：气氛很足但什么也没发生，或反复在同一个点上绕。

### 5. world_rules 世界规则

**问的是：设定有没有真正进入正文并被遵守，而不是停在背景设定里？**

- 世界观、规则、势力、地点有没有在正文里被用到、被触及？
- 有没有违反自己立的规则（比如设定说"不可逆"却逆了）？
- 高分：设定有存在感，且自洽。
- 低分：正文几乎不碰设定，设定像贴上去的；或出现硬伤式的规则冲突。

### 6. ai_voice AI 味控制（越高 = 越不像 AI）

**问的是：读起来像真人作者写的，还是像 AI 生成的？**

- 注意句式是否机械工整、是否堆砌"仿佛/似乎/缓缓/不由得"、是否有模板化结尾（"真正的考验才刚刚开始"）、是否段段同长。
- 高分：句式错落、有手稿感、像人写的。
- 低分：浓重的 AI 腔，工整、空泛、套路化。
- **这一维度分数越高代表越好**（越不像 AI），和其他维度方向一致。

### 7. prose_readability 正文可读性

**问的是：单纯作为文字，读起来顺不顺、有没有画面感？**

- 句长是否舒适、对白是否自然、有没有具体可感的物象（而非抽象叙述）、标点是否正常。
- 高分：流畅、有画面、愿意一直读下去。
- 低分：读着费劲、梗概化、全是"他感到……""局势发生了变化"这类空泛叙述。

### 8. overall 综合体感

**问的是：作为读者，你愿不愿意继续读下去？**

- 这**不是**前面 7 项的平均分，而是你的整体直觉判断。
- 一部小说可能各维度都 7 分却整体平庸，也可能某维度有瑕疵但整体抓人。凭直觉给这个总分。
- 高分：抓人，想追更。低分：读不下去。

## 操作步骤

1. 打开样本的 `samples/{id}.chapters.json`，把 3 章正文从头读一遍（先别想打分，先当读者读完）。
2. 回到每个维度，对照上面的描述给 0-10 分。
3. 把分数填进 `samples/{id}.labels.json` 的 `humanScores`。
4. 把该文件的 `status` 从 `"seed"` 改为 `"annotated"`，`annotator` 填你的标识（名字/缩写均可），`annotatedAt` 填日期。
5. 同步把 `manifest.json` 里对应样本的 `status` 改为 `"annotated"`。
6. 跑 `npm run eval:golden` 查看相关性报告。

## 一致性建议（可选但推荐）

- **同一个人一次性标完所有样本**，口径最稳，先建立趋势。
- 若有两位标注者，可各自独立打分，再比对差异大的维度——分歧大的地方往往是维度定义本身模糊，值得讨论后在本指南里补充。
- 隔一段时间重标时，先重读本指南，避免标准漂移。

## 为什么需要这么认真

评分器（`evaluateNovelQuality`）的每个维度权重和阈值目前都是凭经验定的，没人验证过它准不准。你的人工分就是那把尺子：跑 `eval:golden` 后，相关性高的维度说明评分器和人类判断一致、可信；相关性低的维度（目前预期是 `logic`）说明评分逻辑需要调整。**你打的每一个分，都会成为未来调参对错的裁判依据。**
