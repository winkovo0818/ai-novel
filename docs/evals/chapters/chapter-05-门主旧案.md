# 第 5 章《门主旧案》

- 来源：llm
- 模型：mimo-v2.5-pro
- 字数：3995

正殿前的石坪还泛着潮气。沈言站在队列最末，目光垂着，只看前头弟子袍角下露出的草鞋。赵执事念名字的声音在晨雾里传不远，每个字都像裹着水汽，沉甸甸往下掉。

黑石贴在心口，凉意已经淡了。剑魂的声音比昨夜清晰，在脑海里低低地响：“时辰到了。祭剑要见血，先活过前三轮。”

沈言喉咙动了动，没应声。他知道“前三轮”是什么。柴饦峰考核分九轮，前六轮筛人，后三轮见生死。杂役弟子通常撑不过第二轮。昨晚剑魂把“祭剑”二字点破时，他手里那根烧火钳差点掉进灶膛。三年来他以为只是淘汰，原来是要拿命去喂后山那把断剑。

“沈言，丙字十二。”

赵执事念到他的名字，声音没任何起伏。沈言往前走，草鞋踩在湿石上，发出吱呀一声轻响。他走到木盒前，手伸进去，竹签冰凉。抽出来时，背面刻着个“火”字。

“火字房。”赵执事眼皮都没抬，“去东侧廊下候着。”

沈言捏着竹签转身，听见身后有人低声嘀咕：“杂役抽到火字房，死得最快。”声音很轻，但他听见了。三年来这种话听过太多，以前只当耳旁风，现在知道是真的。火字房考核要过火阵，杂役弟子没有护体灵气，进去就是烤肉。

他走到东侧廊柱边站着，把竹签收进袖袋。黑石在丹田里微微震动，剑魂的声音又起：“火阵伤的是皮肉筋骨，你用鞘气护住心脉和丹田就行。记住，鞘气用一次，虚弱三天。撑过火阵，我带你去查你爹的旧事。”

沈言手指在袖子里蜷了蜷。旧事。昨晚剑魂提到沈恪死于剑气反噬，但不是他自己的剑气。这句话像根刺，扎进他这三年的浑噩里。他一直以为父亲是修炼时出了岔子，连宗门里扫地的老杂役都这么说。

可如果真相不是这样。

廊下陆续站了七八个杂役弟子，都低着头，没人说话。前面新弟子那边倒是有些声响，是抽到好签的在互相道贺。沈言靠着廊柱，视线越过人群，落在赵执事身上。赵执事正在收名册，动作很慢，一页一页地翻。他右手食指第二关节有道旧疤，是刀伤，不是剑伤。

这个细节沈言看了三年，第一次觉得它扎眼。

剑魂说，二十年前后山塌方，死过一批外门弟子。那一年赵执事从杂役升了执事。沈恪也是那一年死的。时间对得上。

沈言往廊柱阴影里又缩了半步。他不能问赵执事。赵执事知道后山裂井的事，知道断剑认沈家血，甚至可能知道祭剑的内幕。但这些话烂在赵执事肚子里二十多年，不会因为他一个杂役弟子就吐出来。

除非他自己去找。

“想查你爹的事，先活下来。”剑魂的声音冷硬，“祭剑要见血，你死了，我也得另找载体。没那么多时间。”

沈言捏紧袖袋里的竹签，竹片边缘硌着指腹。活下来。然后查。这两个顺序不能乱。

前面开始叫人了。新弟子先上，十人一组，进了殿侧的小门。门里约略有热浪涌出来，夹着焦糊味。杂役弟子们缩得更紧，有人开始发抖。

“丙字十二，沈言。”

轮到他了。

沈言从廊柱边走出来，脚步稳，呼吸浅。他跟着前面三个杂役弟子往前走，路过赵执事身边时，赵执事忽然开口：“火阵第三层有幻象，看见什么都别停。停了就出不来了。”

沈言脚步顿了一下。赵执事没看他，眼睛盯着名册上某个名字，手指按在那一页，指节发白。

“谢执事提点。”沈言低声说。

赵执事没再说话，摆了摆手。

小门里的热气扑在脸上，像走进了灶膛。沈言眯起眼，看见前面是一条窄道，两侧墙壁嵌着赤红色的晶石，晶石里火光明灭，把人的影子拉得歪歪扭扭。前面三个杂役弟子走得很慢，最前面那个手已经开始抖。

剑魂在丹田里嗡鸣：“鞘气护体，走。别停。”

沈言提气，丹田里那团模糊的剑鞘轮廓散出凉意，顺着经脉流遍全身。热浪压上来，皮肤发烫，但骨头里还是凉的。他迈步往前走，热风灌进袖口，袍角卷起来，露出手腕。手腕上一道旧疤，是五年前刚来柴饦峰时，劈柴伤到的。

窄道尽头是片空地，地上画着火焰纹路。纹路突然亮起红光，火舌从地面窜上来，有半人高。前面三个杂役弟子惨叫一声，掉头就跑，其中一个撞在沈言肩膀上，把他撞得歪了一步。

火舌卷过来。

沈言没躲。鞘气在心口聚成一点，凉意刺骨。火舌舔到他袍角，烧出焦痕，但没继续往上。他盯着那跳动的火光，想起父亲书房里那盏长明灯。父亲死后，灯就灭了，再也没人点过。

“往前走。”剑魂说，“第三层幻象要来了。”

沈言穿过火墙。眼前忽然暗了，热浪消失，变成一片冰冷的空地。空地中央站着个人，背对着他，穿着柴饦峰执事的青灰袍子，身形佝偻。

那人转过来。

是赵执事的脸，但年轻得多，眉眼间全是戾气。他手里提着把滴血的剑，脚下躺着好几具尸体，尸体穿着外门弟子的袍服。

幻象。沈言提醒自己，别停。

年轻的赵执事朝他走过来，剑尖拖在地上，划出一道血痕。“沈恪的儿子。”他开口，声音和现在的赵执事一模一样，“你爹也是这么死的。”

沈言喉咙发紧。他知道这是假的，但脚步钉在地上，动不了。

“剑气反噬，宗门上报的是走火入魔。”年轻的赵执事笑了，露出被血染红的牙齿，“其实是被后山那把断剑抽干了精血。断剑认沈家血，你爹祭了剑，我们才能在柴饦峰站住脚。”

幻象的脸扭曲起来，血从七窍流出。“你爹临死前把剑魂封进黑石，塞给你娘。你娘抱着你和石头跑了，我们追了三年才找到。”他举起剑，“现在轮到你了。”

火光从幻象背后重新亮起，烧穿了那张脸。沈言猛地回神，发现自己站在火阵尽头，背上全是冷汗，袍子湿透贴在身上。丹田里的剑魂剧烈震动：“出来了。幻象是断剑里的记忆碎片，不是真的。但有些话……”

“是真的。”沈言哑声说。他抬起手，看着掌心。鞘气用了两次，虚弱的感觉已经涌上来，四肢发沉，丹田空荡荡的。

火阵外，阳光刺眼。沈言走出来，腿有点软，扶着墙喘了口气。赵执事站在廊下，正看着他。两人视线撞上，赵执事眼神复杂，嘴唇动了动，最终什么都没说。

沈言站直身体，一步步走回杂役弟子的队列。袖袋里竹签硌着腕骨，他捏紧它，直到指节发白。

火阵幻象里的信息碎片一样砸进脑子：断剑认沈家血，父亲被抽干精血，母亲带着黑石和他逃跑，赵执事那年升执事。这些线索串起来，指向一个名字。蒋阶。

蒋阶是柴饦峰前任门主，二十年前死在后山塌方里。官方说法是镇封断剑时剑气暴走，连带死了七个外门弟子。赵执事就是那七个弟子里唯一活下来的，伤愈后升了执事，接了蒋阶的位子。

沈言靠着廊柱，闭上眼。火阵的热气还残留在皮肤上，但心里冷。如果蒋阶才是用沈家血祭剑的人，那赵执事在其中扮演什么角色？活下来的弟子？还是帮凶？

剑魂的声音沉下去：“去查蒋阶的旧档。柴饦峰所有记录都存放在偏殿阁楼，钥匙在赵执事腰带上。”

沈言睁开眼，看向赵执事。赵执事正在安排下一轮考核，侧影映在殿门光影里，腰带上确实挂着一串钥匙，铜制的，在晨光里泛暗。

“怎么拿？”沈言用气息问。

“等。”剑魂说，“考核结束会乱一阵子。你只有半柱香时间。”

沈言垂下眼，手指在袖子里松开竹签。半柱香。偷钥匙，查旧档，再还回去。只要被发现，不用等祭剑，赵执事当场就能废了他。

但他得去。

为了父亲那句“不是自身剑气反噬”，为了母亲抱着他逃的三年，为了火阵幻象里那张扭曲的脸。

前面又有人惨叫着从火阵里逃出来，滚在地上打滚，身上的火苗被旁人用湿布扑灭。焦糊味混着皮肉烧焦的臭气飘过来。沈言捏了捏手腕上那道旧疤，疤痕凸起，硌着指腹。

轮到他了。赵执事点了他的名字。

沈言从廊柱边直起身，走向那片翻腾的热浪。袖袋里的竹签边缘锋利，割着腕子，他没管。心跳很快，但呼吸压得很平。

火墙在他面前分开。他走进去，热浪裹住全身。

这一次，他没看幻象。眼睛盯着窄道尽头那扇铁门。门后是偏殿阁楼的方向。

鞘气在丹田里聚拢，凉意护住心脉。火舌卷过来，他侧身避开，袍角还是烧焦了一片。铁门越来越近。

身后传来赵执事的声音，隔着火墙听不真切，像在喊什么。沈言没停。手按上铁门时，门是烫的，但他没松开。

门推开了。

冷风灌进来，吹散了背后的火气。沈言闪身进去，反手关上门。门栓落下，咔哒一声，锁住了外面的火光和人声。

他靠在门板上，喘了几口气。虚弱感更重了，膝盖发软。但眼睛已经适应了黑暗，看见面前是往上的木楼梯，楼梯尽头有扇小窗，透进一点灰光。

剑魂的声音很轻：“上去。旧档在第三排架子，标着‘蒋’字的木匣里。”

沈言扶着墙，一步步往上走。楼梯吱呀作响，灰尘扬起来，呛进鼻子。他捂住口鼻，压住咳嗽。

阁楼很小，堆满木架和木匣。灰尘很厚，没人来过。沈言找到第三排架子，最底下有个木匣，上面用墨笔写着“蒋阶”二字，字迹已经褪色。

他蹲下身，手指摸到木匣上的铜锁。锁生了锈，很紧。沈言从发髻里抽出那根铁簪。母亲留下的，簪尾磨得很尖。他把簪尖插进锁孔，拧。

锁簧松动，咔哒一声。

木匣掀开，里面是一叠泛黄的纸。纸张脆得要碎，沈言小心地翻开第一页。是蒋阶的履历，柴饦峰门主，修为剑魄境，死于后山塌方。再往后翻，是事故记录，写得很简略：“封镇断剑，剑气暴走，七名弟子身亡，门主蒋阶殉难。”

沈言手指停在最后一行。下面有一行小字，是后来加上去的，墨色不同：“死者：沈恪、王七、李二……”父亲的名字排在第一个。

纸张边缘有油渍，像有人拿着这份记录反复看过。沈言翻到最后一页，是封存令，盖着掌门印。印泥已经干裂，但字迹清晰：“旧案封存，不得外泄。知情者。”下面列了三个名字，前两个被墨涂掉了，第三个是“赵铁柱”。

赵执事的名字。

沈言盯着那三个字，手指发冷。知情者。涂掉的两个是谁？为什么涂掉？赵执事为什么还留着名字？

楼下忽然传来脚步声，很轻，但正在接近楼梯口。

沈言心脏猛地一缩。他抓起那张记录纸，塞进怀里。木匣来不及锁，就那么敞着放回架子。转身时膝盖撞到旁边的木架，灰尘哗啦落下来，呛得他眼前发黑。

脚步声更近了。

沈言咬牙，闪到阁楼最角落的阴影里，屏住呼吸。鞘气在丹田里乱窜，虚弱感让他眼前发晕。他握紧铁簪，尖端对准楼梯口。

楼梯吱呀一声。

有人上来了。
