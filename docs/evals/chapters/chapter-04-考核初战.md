# 第 4 章《考核初战》

- 来源：llm
- 模型：mimo-v2.5-pro
- 字数：1954

正殿前的石坪还湿着，昨夜的雨水没干透，从屋檐滴下来，砸在青石板上，啪嗒一声，又碎成几瓣。沈言混在杂役弟子里，站在最外侧，肩膀缩着，头微微低垂。袍袖里的手攥着那块黑石，石头贴在掌心，凉意一丝丝往骨头里钻。

前面的人排成几列，新弟子在前，杂役在后。赵执事站在殿门台阶上，手里捧着名册，念一个名字，就有人上前，从他身侧的小木盒里摸出一枚竹签。签子背面刻着字，正面是数字。

“张三，乙字七号。”

“李四，丙字三号。”

声音干巴巴的，像枯枝折断。沈言听着，呼吸放得很轻。他知道规矩，杂役弟子抽的是丁字签，最末等，比试对手也都是些没入门墙的苦力。赢了，才有资格进内院做三年真正的弟子；输了，废去修为，逐出山门。废去修为的说法好听，其实就是打断经脉，这辈子连重力气活都干不动。

“沈言。”

他往前挪了两步，靴底踩在湿泥上，陷下去一点。赵执事没看他，手指在名册上划了一下，指向木盒。沈言伸手进去，竹签冰凉，沾着露水。他摸到一枚，抽出来。

丁字十二号。

他把签子攥进手心，退回人群里。周围有目光扫过来，带着审视和不屑，很快又移开。一个杂役而已，谁在乎。

比试在石坪两侧的木台上。台子三尺见方，围着粗绳，说是绳，其实是浸过桐油的麻索，硬得像铁条。沈言站在台下，看着台上两个新弟子对练。拳脚生风，但花架子居多，偶尔打中了，也像隔靴搔痒。台下有人叫好，大多是捧场的，声音稀稀拉拉。

轮到他的时候，日头已经爬到头顶。湿气蒸上来，混着汗味，闷得人透不过气。

对手是个壮实的少年，比沈言高出半个头，胳膊上的肌肉把袖子撑得鼓起来。他认得，孙奉，柴饦峰管柴房的杂役头，手下有七八个人，平时克扣杂役的口粮，换钱去山下赌。孙奉抽的是丁字十一号，两人挨着，正好撞上。

孙奉跳上木台，脚一跺，台子晃了晃。他咧开嘴，露出一口黄牙：“沈火夫，巧了。”

沈言没接话，低头爬上木台。台面湿滑，他脚底打了个趔趄，手撑在地上，才稳住身子。台下传来几声嗤笑。

赵执事站在台边，手里拿着名册，眼神淡漠。他抬手：“开始。”

孙奉动了。没花架子，直接一拳砸向沈言面门。风压过来，带着汗臭。沈言往旁边躲，肩膀还是被擦到，钝痛传来，他踉跄着退了两步，背撞在麻绳上。

“站稳了！”孙奉吼着，又是一拳。这次打在沈言小腹。沈言弯下腰，干呕起来，酸水涌到喉咙口。他得忍，杂役弟子的比试，赢了也得赢得狼狈，太出挑会引人注目。但孙奉没给他喘息的机会，一脚踹过来，正中膝盖。沈言跪倒在地，膝盖磕在木板上，骨头发出脆响。

“认不认输？”孙奉居高临下，脚踩在沈言手背上，碾了碾，“认输就滚下山，别在这儿碍眼。”

沈言没吭声。手背的骨头像要裂开，疼得眼前发黑。他感觉到心口那块黑石在发烫，不是幻觉，是实实在在的温度，顺着血管往丹田流。丹田里，那团剑鞘轮廓的气旋转得快了些，一丝凉意冲上来，护住了心脉。

他不能认输。认输了，就真成了废人，父亲的事，断剑的事，全成了死局。

孙奉脚上加力：“聋了？”

沈言抬起头，额头上全是汗，混着灰尘，往下淌。他盯着孙奉的眼睛，那眼里有得意，有狠戾，还有一丝不易察觉的急躁。孙奉也在怕，怕输了丢脸，怕赢了不光彩。

“我……我认……”沈言声音发颤，话没说完，猛地抬手，抓住了孙奉的脚踝。

孙奉没料到他敢反抗，愣了一下。就这一瞬，沈言丹田里的鞘气冲了出来，并非刀剑的锋锐。一股震荡的力道，顺着掌心传进孙奉的脚踝。

嗡。

孙奉只觉得小腿一麻，整条腿像被木槌敲中，骨头都在颤。他怪叫一声，往后退去，脚踩在湿滑的台边，没站稳，一屁股坐倒在地。

台下静了一瞬。

沈言撑着膝盖站起来，身子晃了晃，扶住麻绳。心口的黑石烫得吓人，丹田里空了一块，力气被抽走大半，骨头缝里都在发酸。鞘气用一次，虚弱三天，这笔账他清楚。

孙奉爬起来，脸涨成猪肝色。他想冲过来，但右腿还在抖，踉跄了一步。台下有人喊：“孙奉，你行不行啊？”是平时跟他混的几个杂役，声音里带着戏谑。

孙奉停住了。他盯着沈言，眼睛里要喷火，但更多的是一种困惑和惊惧。那一脚的力量不对劲，不像拳脚，倒像被什么东西震穿了骨头。

赵执事在台下咳了一声：“比试点到为止。沈言，丁字十二号，胜。”

沈言没看赵执事，低头往台下爬。手抖得厉害，抓了两次麻绳才抓住。落地的时候，膝盖一软，差点跪下去。他用手撑住地面，掌心被碎石硌得生疼。

人群散开一条路，没人扶他。沈言拖着步子往火房走，背上的汗湿透了衣衫，贴在皮肉上，又冷又重。他摸出怀里的黑石，石头已经不烫了，凉丝丝的，像什么都没发生过。但他知道，刚才那一震，不只是鞘气。丹田里的剑鞘轮廓，在鞘气涌出的瞬间，传来一丝很细微的共鸣，像有什么东西在裂井深处，隔着山石，回应了他。

他得回去，躺下，攒够力气。三天后，是真正的祭剑。
