# 第 3 章《裂井剑鸣》

- 来源：llm
- 模型：mimo-v2.5-pro
- 字数：2595

灶膛里的火苗突然矮了一截。湿柴烧出的烟又厚又腻，顺着门缝往外卷。

赵执事站在门口，袖口还在滴水。他没进来，就那么堵着，目光在沈言沾满炭灰的脸上停了片刻。

“掌门的传令牌，你收到了。”

沈言没答话，用火钳把最底下那根半焦的木头翻了个面。火星溅起来，烫在手背上，他缩了一下，动作很轻。

“三天后考核，规矩你懂。”赵执事往前踏了一步，靴底碾着地上的泥水，“掌门召见是掌门的事，但在这柴饦峰，该走的流程，一步都不能少。”

“弟子明白。”沈言低头，炭灰混着汗，从下巴滴到衣襟上。

“明白就好。”赵执事声音压低了些，“后山那口裂井，你最好别再去。剑魂的事，不是你一个杂役弟子能碰的。”

沈言手指收紧，火钳的木柄硌得掌心生疼。他听出来了，赵执事知道。并非知道剑魂认主。知道他去过裂井，知道那里有东西。为什么现在才点破？因为掌门那块木牌。

“弟子不敢。”他说。

赵执事哼了一声，没再说话。转身时，泥水在门槛上甩出一道深色的痕。脚步声远了，沈言才直起身，把火钳扔进柴堆。金属碰木头，闷响一声。

他没回火房里间，而是从后墙的破洞钻了出去。雨小了，天还是灰的，后山的路被踩成了泥浆。他走得很慢，手一直按在心口。那里什么也没有了，黑石沉进丹田，但皮肤底下总像有东西在动，一跳一跳，随着心跳。

裂井在断崖底下。井口用乱石堆着，只留一人宽的缝。沈言蹲下，手指抠进石缝，摸到了昨天留下的记号。一道浅浅的划痕。划痕还在，没人动过。

他钻进去。

井壁是湿的，青苔滑脚。往下爬了十来丈，脚下踩到实地。空气变了，潮气里混着铁锈味。沈言从怀里摸出火折子，吹亮。火苗很小，照出前面一条窄道，道尽头是黑的。

他往前走。火光晃在石壁上，影子拉得很长。走到窄道尽头，火折子烧到了底，烫手。他松开，火光灭了，黑暗涌上来。不是全黑，有极淡的光从顶上渗下来，像月色，但今天没有月。

丹田里那点东西动了。不是疼，是牵扯，像有根线从肚脐眼往上拽。沈言吸了口气，顺着那感觉往前迈了一步。

脚踩空了。

他往下坠，风从耳边刮过去，带着呜咽声。不是风声，是什么东西在哭，又像在笑。坠了大概两三息，背脊撞上硬物，疼得他闷哼一声。不是石头，是木头，腐烂的木头。

他躺在黑暗里，喘了口气。牵扯感更重了，从丹田直抵喉咙，他得用力咽，才能把那股翻涌压回去。

“你来了。”

声音直接响在脑子里，没有方位。是剑魂。昨天它自称“吾”，今天换了词，更近，更贴。

沈言没起身，就那么躺着，手摸到身下的木头。是朽掉的棺板，边角都烂了。他手指抠进去，抠下一块碎屑。

“赵执事不让我来。”他说。

“他拦不住。”

“他知道这里有东西。”

“他知道的是二十年前的东西。”剑魂的声音平，像在陈述，不是解释，“沈恪死前一年，这井里塌过一次，埋了七个内门弟子。柴饦峰对外说修炼走火，其实是剑气反噬。你父亲查过，没查出结果。”

沈言手指停了。碎屑扎进指甲缝，有点疼。

“他为什么查？”

“因为他听见了声音。”剑魂说，“像你现在听见的一样。剑鸣。这井底镇着一把断剑，断剑有魂，魂很弱，但认得血。”

“认得谁的血？”

“认得沈家的血。”

沈言坐起来。黑暗里什么都看不见，但他盯着声音来的方向。丹田里的牵扯感变成了热，顺着经脉往四肢走，手心开始发烫。

“我父亲……怎么死的？”

“被剑气反噬。”剑魂顿了顿，“但不是他自己的剑气。”

“谁的？”

“不知道。我沉睡时，他已经死了。我醒过来，你已经在火房烧火。”剑魂的声音淡下去，“但我知道一件事：沈恪死后第三天，柴饦峰清洗过一批外门弟子。赵执事是那年升的执事。”

沈言喉咙发紧。他想起火房墙上那些焦黑的痕迹，想起赵执事袖口洗不净的褐渍。原来不是油。

“你想让我做什么？”

“活过三天后的考核。”剑魂说，“考核不是比试，是祭剑。柴饦峰每年用杂役弟子的血养后山那把断剑，剑气反噬的根源就在这里。你活下来，我能借你的鞘气探一次井底。探清楚了，你父亲的事，我能告诉你更多。”

“鞘气是什么？”

“你现在丹田里那个轮廓，就是鞘。鞘能容魂，也能镇魂。”剑魂声音低了，“我教你用鞘气护住心脉，剑气反噬时，你能多撑一刻钟。就一刻钟，够不够？”

够不够？沈言不知道。考核是生死关，他知道。但一刻钟，比他现在拥有的任何东西都长。

“好。”他说。

声音落下去，丹田里的热忽然炸开，像滴进冷水的滚油。沈言蜷起来，额头抵着棺板，木屑刺进皮肤。热流冲上喉咙，他张嘴，没出声，只有一口铁锈味涌上来。不是血，是剑气，从丹田剑鞘的轮廓里渗出来的，很细，像针，扎进四肢百骸。

痛。但不是坏痛，是打通什么的痛。他听见自己骨头在响，噼啪声，很轻，像柴火在灶膛里爆。

热流走了三圈，退回丹田。沈言喘着气，手摸到心口。皮肤底下，那个轮廓清晰了一点，硬的，像多了块骨头。

“鞘气初成，能护心脉，也能伤敌。”剑魂的声音又响起，这次更远了，像隔着什么，“但别乱用。你身子太弱，用一次，至少躺三天。三天后就是考核。”

沈言点头，没说话。他爬起来，摸索着找来路。手指碰到石壁，湿滑，往上攀。爬了十来丈，看见井口那点灰白的光。钻出去时，雨已经停了，天边裂了条缝，露出脏兮兮的夕照。

他回头看了一眼裂井。乱石堆着，和之前一样。但底下有东西动了，是断剑，还是别的什么，他说不清。

回到火房时，赵执事不在。灶膛的火早灭了，只剩一堆白灰。沈言蹲下来，用火钳拨了拨，灰里埋着半块没烧完的湿柴。他捡起来，捏在手里，湿木头扎手。

掌门的传令牌还在怀里，硬硬的。他掏出来，对着残光看。木牌背面，刚才没注意的地方，刻了一个很小的“赦”字。

赦免的赦。

沈言把木牌塞回去，手指碰到丹田的位置。那里温温的，像捂了块热石头。他站起来，把湿柴扔进灰堆，拍了拍手。

门外传来脚步声，这次不是赵执事。是扫地的哑巴老仆，佝偻着背，拖把破扫帚，在泥地上划拉。老仆看了他一眼，浑浊的眼珠动了动，扫帚指向正殿的方向，然后垂下头，继续扫。

沈言没动。火房里只剩他，还有地上那摊泥水印子。赵执事的靴印深，他的浅，交叠在一起，分不清谁先谁后。

他走到门口，回头看了一眼灶膛。灰堆里，那半块湿柴又开始冒烟，一丝一丝的，往上飘，很快散了。

然后他转身，往正殿的方向走。步子不快，鞋底踩在泥上，声音闷闷的。丹田里那点温热还在，跟着心跳，一下，一下。
