# 第 2 章《黑牌入手》

- 来源：llm
- 模型：mimo-v2.5-pro
- 字数：1611

灶膛里的火苗舔着湿柴，发出嗤嗤的声响。沈言盯着那几缕挣扎的青烟，后山的谈话像根冰锥钉在脑子里。剑魂源自父亲，活过考核才能知道真相。这交易听着简单，可考核是三天后，赵执事要他今晚就“把该认的认了”。

门外脚步声停了。

“沈言。”是赵执事的声音，沙哑里带着不耐烦。

沈言没动，又塞了一根湿柴进去。浓烟涌出来，呛得他咳了两声。他得把这摊子收拾完，火房的差事是他在这里待下去的理由，哪怕只剩三天。

“聋了？”门被推开，泥水溅进门槛。

沈言这才起身，用沾满炭灰的手背擦了擦额头。赵执事站在门口，灯笼的光从他身后漏进来，把他半边脸映得晦暗不明。他手里捏着一块黑木牌，不是掌门那块，更粗糙，边缘还有毛刺。

“掌门的牌子。”赵执事把木牌扔过来，沈言接住。木头冰冷，比他想的要沉。“明早辰时，正殿候着。”

沈言捏着木牌，指腹摩挲过粗糙的表面。太重了，而且冷得不像木头。“赵执事，考核……”

“考核照旧。”赵执事打断他，眼神在沈言脸上刮了一遍，“掌门问什么，你答什么。不该说的，一个字也别漏。懂？”

他没说不懂的后果。沈言点头，把木牌揣进怀里，紧贴胸口。那里的皮肤下，剑魂沉降后留下的空荡感隐隐作痛。

赵执事没走，盯着他：“手伸出来。”

沈言迟疑了一瞬，伸出右手。掌心全是黑灰。赵执事一把抓住他的手腕，力气大得骨头生疼。另一只手从袖子里摸出一枚更小的、暗红色的木片，按在沈言掌心。

“握紧了。”赵执事低声道，“这是你的考牌。弄丢，或者让别人碰了，你就不用去正殿了，直接去后山喂灵兽。”

木片边缘锋利，割得掌心生疼。沈言用力握紧，感觉到木片上细微的刻痕。他应了声“是”。

赵执事松手，盯着他把木片收进怀里，和掌门那块黑牌分开。没再说话，转身走了。泥水声啪嗒啪嗒远去。

沈言回到灶前蹲下，摊开双手。左手掌心一道浅红的印子，是考牌割的。右手全是灰。他拿起火钳，拨了拨炭，火星子溅起来。

怀里的两块木头硌着皮肉。一块冷，一块带着血的铁锈气。

“他给了你一块带符的木头。”

剑魂的声音直接响在脑海里，比刚才清晰了一丝，但依旧虚弱，像隔着厚布说话。

沈言手里的火钳顿住。他没抬头，继续拨弄炭火。“符？”

“追踪符。低劣的手法，但对你够用了。”剑魂顿了顿，“捏碎，或者扔掉，施术者立刻能察觉。你的位置，你的心跳，甚至你血气涌动的方向，都瞒不住。”

沈言的指尖掐进火钳的木柄。炭灰的气味混着雨水的潮气钻进鼻子。他想起赵执事按他掌心时那一下，力道大得不寻常。

“掌门那块呢？”他问。

“干净。”剑魂的声音更弱了，“但那块……本身就有问题。气息太沉，不是你能沾的东西。”

沈言把火钳放下，从怀里掏出那两块木头。黑牌躺在左手，沉而冷，触手生温，像一块死掉的玉。红牌在右手，小，粗糙，边缘的毛刺扎着皮肤。他盯着红牌上那些细密的刻痕，看不懂，但能感觉到里面有什么东西在微弱地搏动，和自己的心跳一点点同步。

他必须带着这块红牌去正殿。扔了，赵执事会知道。藏了，赵执事也会知道。赵执事要他握着，他就得握着。

“为什么不直接揭穿？”沈言在心里问。

剑魂沉默了片刻。“你现在揭穿，赵执事最多受罚。而你，会立刻成为柴饦峰所有盯着你的人眼里的刺。考核不用等了，今晚他们就会让你‘意外’死在去后山的路上。”

“那我就一直握着？”

“握着。它探到的东西，我能截掉大半。只要你心口的剑鞘轮廓不散，它的探查就是雾里看花。”剑魂的声音断断续续，“但……很耗。今晚，别动用任何气力，也别让情绪有太大起伏。明天正殿，稳住了。”

沈言把两块木头重新塞回怀里，左边一块，右边一块，隔着里衣的粗布。黑牌的冷和红牌的尖锐都清清楚楚。

他站起身，走到门边。雨还在下，柴饦峰的正殿在夜色里只有一团模糊的黑影，檐角挂着的风灯像几点将熄的鬼火。

掌门为什么要见他？赵执事为什么急着给他一块追踪符？

怀里，红牌随着心跳，一下，一下，顶着他的肋骨。
