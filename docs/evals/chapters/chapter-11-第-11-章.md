# 第 11 章《第 11 章》

血从指尖滴下来，砸在石阶上。

不，不是滴。是沿着石棱的凹槽流。沈言盯着那道暗红色的细线，它渗进青苔底下，被石头吸干，只留下一小片颜色更深的湿痕。剑魂没说血要多少。他用的是左手中指，伤口是被石棱边缘划开的，不深，但血珠子冒得很快，一颗接一颗，悬在指腹下方，摇摇欲坠。

石阶上方的黑暗里，传来一丝声响。

不是风。是金属。极细微的、持续的震颤，像有人把一块铁片按在磨石上来回地拖。声音顺着石壁往下滚，撞在沈言耳膜上。他认得这个声音。在阁楼缝隙里听过，蒋阶离开后，那块黑铁牌被他攥在手里，指节发白时发出的就是这种闷响。

但更近。近得多。

“它醒了。”剑魂的声音忽然冒出来，贴着颅骨内壁，压得低低的。不是命令，是陈述。但沈言听出了别的东西。一种紧绷的、收缩的情绪，像弓弦拉满后手腕的颤抖。

“断剑？”他喉咙发干。

“不止。”剑魂沉默了两息，“祭阵在吸。”

吸什么？

沈言没问出口。他的手开始抖。不是冷。是丹田深处，那道剑鞘轮廓在跳。一下，又一下，像心脏，但比心跳沉，每一下都牵着脊骨往下坠。虚弱感不再是漫上来，是砸下来。他膝盖一软，半跪在石阶上，左手撑住沟壁。指尖的血蹭在石头上，划出一道歪斜的红痕。

石阶上方的金属震颤声停了。

死寂。

然后，井壁亮了。

不是火光。是暗红色的符文，从他头顶上方三丈处开始，一道一道地活过来。像血管在石头底下搏动，每一次搏动，符文的光就亮一分，蔓延一寸。光顺着井壁往下爬，爬过沈言刚才留下的血痕，爬过他按在石壁上的手背。光是冷的，但被它照到的皮肤却发烫，像被细针扎着。

“鞘气。”剑魂的声音急了，“护住心脉！”

沈言没动。他在看那些光。光蛇的尽头，指向井底。井底的黑暗里，那片金属震颤声又响起来了，这一次带着回音，嗡嗡的，撞得整个井道都在共振。他看见自己的血痕被光吞没，看见光蛇在井壁上分叉、汇聚，织成一张巨大的、收紧的网。

网的中心，在井底。那里有什么东西在醒。

“退吗？”他问。声音哑得不像自己的。

剑魂没回答。

沈言抬起头，看向来时的路。石阶下方，排水沟的黑暗像一张巨口。铁盖外面是蒋阶。火阵的热浪，考核广场的喧哗，还有乙字四号那个替死鬼弟子被抛上天的惨叫。退回去，钻回那条烂泥沟，爬回地面，然后呢？蒋阶在等子时一刻。赵执事不知去了哪里。锁魂符下落不明。他什么都不知道，什么都没抓住，只有满手的泥和血，还有一副被鞘气掏空半截的身子。

他低头，看自己的手。中指的伤口还在渗血，血珠子悬着，映着井壁上暗红色的光。光很冷，照得他指节发青。

“它在认主。”剑魂忽然说。

认谁？

“你的血。”剑魂的声音顿了顿，像是在斟酌字句，“你用血引路，石阶认了你，井壁认了你，现在……断剑也在认。”

沈言盯着那滴血。血珠子终于坠下来，砸在石阶上，啪的一声，碎成几瓣。每一瓣都被光蛇接住，吞没，然后光蛇的搏动更快了，朝着他涌来。

他忽然明白了。

蒋阶要他来，不是让他看的。是让断剑看的。看他的血，记他的气息。锁魂符是引子，沈言是祭品。赵执事送不送锁魂符，送到哪里，其实不重要。重要的是沈言得来。得用血，得亲自走进这口井，得让断剑认得他。

“所以，”沈言听见自己的声音，平静得可怕，“我没得选。”

他站起身。膝盖抖得厉害，他扶着井壁，手掌按在那些搏动的暗红符文上。符文的光烫得他手心发红，但他没缩手。他用右手，撕下左袖内衬的一条布，缠住还在流血的中指。布很快被血浸透，暗红色。

他开始往上爬。

石阶很陡，每一级都很窄。他的手抓着井壁凸起的石棱，石棱边缘刻着浅痕，像是脚窝，但比脚窝小。他得把手指塞进去，才能稳住身体。左手缠着布，血渗出来，把布浸成更深的红。右手抓着石棱，指甲抠进缝隙，苔藓碎在指缝里。

光蛇在他身边游动，像活的。它们避开他的手，但紧紧贴着他爬过的井壁，像在记录他的路径。金属震颤声从井底传来，越来越响，不再是嗡嗡的闷响，是清晰的、带着锋刃的锐鸣。像剑在鞘中挣动，要出来。

剑魂不再说话。但沈言能感觉到它。在丹田深处，那道剑鞘轮廓在震颤，和井底的锐鸣同频。每一次震颤，他的脊骨就往下坠一分，虚弱感就加重一分。他爬了十步，停下来喘气，冷汗从额角滑下来，滴在石阶上，和血混在一起。

他抬头看。井口还很远。光蛇已经布满整个井壁，暗红色的光把井道照得一片血亮。井底的黑暗里，那片锐鸣忽然拔高，刺得他耳膜生疼。

然后，光暗了。

不是熄灭。是收缩。所有光蛇猛地往井底缩去，像被什么东西吸住。井道重新陷入黑暗，但黑暗里多了东西。沈言听见一种声音，很轻，像布帛撕裂，又像水滴落进深潭。声音从井底传来，一下，一下，缓慢而坚定。

剑魂的呼吸声，在他颅骨里响起。

“快。”它说，“别让它认完。”

沈言咬了咬牙。他松开左手，让缠着布的伤口暴露在空气里。血还在渗，一滴一滴，落在石阶上。他用右手抠进石棱，把身体往上拉。一步，两步。脚掌踩到湿滑的苔藓，差点打滑。他撑住，膝盖撞在石阶边缘，疼得他抽了一口冷气。

井底的声音变了。

不再是布帛撕裂。是低语。极轻微的、含混不清的低语，像很多人同时在说话，但又压得很低，听不清词句。低语声顺着井壁往上爬，爬过沈言的脚踝，爬过他的膝盖。被低语爬过的地方，皮肤发麻，汗毛倒竖。

他还在爬。

五步。六步。左手伤口的布松了，血滴得更快。他停下来，用牙齿咬住布头，重新缠紧。牙齿碰到了血，腥甜的铁锈味在嘴里散开。

井口近了。

光从上面漏下来，不是天光，是另一种光。惨白的，冷的，像月光被冰镇过。光落在井壁上，照出那些暗红色符文的残迹。符文已经褪色，但还在，在石头上留下烧灼般的黑痕。

沈言爬到最后一级石阶。他抓住井口的边缘，手指抠进石缝。石缝里很干，没有苔藓，但有别的东西。他摸到一道刻痕。刻痕很深，边缘锋利，像是用刀尖一笔一划凿出来的。他用指腹顺着刻痕摸过去，摸到一个字的轮廓。

“沈。”

他的手停住了。

井底的低语声，忽然停了。死寂再次降临。然后，那片锐鸣又响起来，这一次，就在他脚下。井底的黑暗里，有什么东西在动。

沈言撑着井口，把身体拉上去。

他半跪在井沿边，低头往下看。

井底很暗，但不是全黑。那里有东西在发光。光是暗红色的，很微弱，像余烬。光里，他看见一截断剑。剑身插在井底的碎石里，只剩上半截。剑柄的缠绳散开了，露出底下青铜色的柄骨。剑身在震，极轻微地、持续地震。

震颤的源头，是剑身上的裂纹。裂纹里，渗出暗红色的光。

光蛇从裂纹里游出来，一条，两条，三条。它们贴着井壁往上爬，爬过那些烧灼的黑痕，爬向沈言所在的井口。它们的速度很快，眨眼就爬到了一半。

沈言看见自己的血，从石阶上一路滴下来，滴进井底，滴在断剑附近。血珠子落在碎石上，没有渗进去，而是被光蛇接住，吸走。每吸走一滴血，光蛇就亮一分，断剑的震颤就强一分。

低语声又响起来了。

这一次，沈言听清了。不是很多人。是一个声音。一个极年轻、极疲惫的声音，在反复地、单调地重复一句话：

“……锁住……别让它……出来……”

沈言的脊背僵住了。

那是他自己的声音。
