# 第 8 章《柴门断剑》

- 来源：llm
- 模型：mimo-v2.5-pro
- 字数：2425

排水沟的铁盖在身后合拢时，沈言听见地面上的火啸声忽然变远了。潮湿的泥水没过脚踝，黑暗像一块湿布裹住全身。他摸着沟壁往前挪，指尖触到苔藓，滑腻腻的。
空气里有铁锈和陈年积水的腐臭味。
剑魂的声音在颅骨里嗡嗡作响：“三步左转，有石阶。”
沈言停住。石阶？排水沟通向后山裂井的路线，剑魂昨晚只说了大方向。他蹲下身，手掌按在湿滑的沟底，摸到一块凸起的石棱。石棱边缘刻着浅痕，像某种符文的一部分。
他没动。蒋阶要他子时一刻到裂井，锁魂符现在在赵执事手里。赵执事会去送吗？半个时辰够不够？蒋阶如果提前发现，赵执事就是第一个死的。
死掉的合作者比活着的可靠。
沈言把这句话嚼碎咽下去。喉咙干得发痛，他咳了一声，声音在狭窄的沟道里闷闷地弹跳。石阶就在左边，往上通向黑暗，水滴从阶缝里渗出来，滴在脚边。
他爬上第一级。靴底打滑，膝盖撞在石棱上，刺痛钻进骨头。第二级。第三级。爬到第七级时，头顶透出一线微光，不是天光，是某种暗红色的、脉动的光。
裂井的光。
沈言伏低身子，从石阶边缘的缺口望出去。
裂井比他想象的更深。井壁是暗红色的岩石，像被血浸透后又风干了千年。井底没有水，只有一圈一圈的符文从中心往外扩散，最中心插着一柄剑。或者说，半柄剑。
断剑。
剑身只余一尺三寸，断口处参差不齐，像被巨力硬生生拗断的。剑柄是黑铁所铸，缠着的旧布条早已朽烂，露出底下锈蚀的铁环。但断口处没有锈，那里闪烁着一层薄薄的、活物般的光。
暗红色的光正从断口里涌出来，顺着井壁的符文往上爬。
祭剑阵。
沈言感觉到丹田里的剑鞘轮廓在发烫，不是疼痛，是某种共鸣，像两块磁石隔着皮肉相互吸引。剑魂的声音变了调，不再是低语，而是夹杂着杂音的嘶鸣：“剑……在这里……”
他知道那是什么。柴饦峰建宗立派的根基，镇压此地气脉的封印核心，也是蒋阶要用来剥离他剑魂的祭器。二十年前，赵执事父亲的血手印就封在这井壁上。现在血印碎了，封印松动，所以蒋阶能假死回归，能设下这场祭剑局。
井边守着两个执事弟子。沈言认得他们，常跟在赵执事身后，脸上总带着那种柴饦门弟子特有的、半死不活的漠然。此刻他们蹲在井沿，一人手里捏着半块饼，饼屑掉进井里，被暗红的光吞没。
“……乙字四号那小子，你看见没？”左边那个嚼着饼，声音含糊，“火阵里没烧死，钻排水沟跑了。”
右边那个往井里啐了一口：“跑得掉？子时一刻祭剑阵一开，锁魂符指哪儿，魂就往哪儿飞。门主给他符，就是给他脖子套绳。”
沈言的手指抠进石缝。锁魂符。赵执事现在应该正拿着那枚铜符，往正殿阁楼去。如果他把符放在门内第三块地砖下，子时一刻，祭剑阵就会抽走阁楼里残留的蒋阶气息。
如果他被抓住。如果他反悔。如果蒋阶根本没去阁楼。
太多如果。
沈言舔了舔嘴唇。嘴里有泥沙的涩味。他需要那柄断剑。祭剑阵以断剑为核心，断剑若拔出，阵就乱了。蒋阶的计划全系于此阵，阵一乱，赵执事那边成不成功，都有了转圜余地。
拔剑有代价。剑魂说过，鞘气护心脉，用一次弱一次。他用了不到一成，虚弱感已经缠上骨头。拔断剑需要更多。也许会直接掏空他。
井边那两个弟子开始换班。左边那个站起来，伸了个懒腰，往石阶这边走。脚步声靠近。
沈言缩回缺口。石阶窄，无处可躲。他听见靴子踩上第一级，第二级，第三级。呼吸声近在咫尺。
五步。四步。三步。
沈言摸到腰间。那里别着烧火钳，他从灶房带出来的，一直没扔。钳头磨得锋利，能当短刀使。
两步。
他猛地从缺口扑出去。不是扑向那弟子，是扑向井沿。身子在空中拧转，烧火钳脱手掷出，不是掷人，是掷向井底那柄断剑的剑柄。
钳尖撞上铁环，发出“锵”的一声刺响。
井壁的符文猛地亮了。暗红色的光浪从井底炸开，掀翻了另一个啃饼的弟子。沈言摔在井沿，半个身子探出井口，热浪扑面，烧焦了他的睫毛。
丹田里的剑鞘轮廓炸开似的痛。他咬紧牙，右手抓住井沿的石棱，左手伸向井内。
够不到。还差一臂。
那被掀翻的弟子爬起来，满脸是血，嘶吼着扑过来。沈言左脚蹬在井壁上，借力把身体又往前送了半尺。指尖触到了铁环。冰凉，然后是滚烫。
他抓住了。
拽。
拽不动。
断剑像长在井底，纹丝不动。祭剑阵的光更烈了，井壁开始震动，碎石簌簌往下掉。那弟子抱住沈言的腰，往后拖。沈言听见自己的肋骨在嘎吱作响，喉头涌上腥甜。
剑魂的声音差点在咆哮：“鞘气！灌进去！剑认鞘！”
沈言把丹田里最后那点微弱的气，全逼进了左臂。气顺着手臂经脉冲进铁环，铁环发红，像烧透的炭。井底传来一声低沉的、金属断裂般的悲鸣。
断剑松了。
他拔出来了。
惯性让两人往后摔。沈言抱着那半截断剑，背脊撞上井沿的石棱。剧痛让他眼前发黑。那弟子压在他身上，手还掐着他的脖子。
沈言用断剑的剑柄，砸向那弟子的太阳穴。
一下。两下。手松了。
他推开尸体，咳着血坐起来。断剑躺在膝头，暗红的光一寸寸褪去，露出底下锈迹斑斑的铁。剑柄处，旧布条彻底碎了，露出三个刻进铁里的字：
柴饦门。
井边的符文暗了。震动停了。
但地面还在震。远处传来崩塌的巨响，是广场那边的方向。火阵的声音变了，不再是火焰的呼啸，而是某种……哭嚎。
沈言撑着井沿站起来。他低头看手里的断剑，看剑柄上那三个字。柴饦门。这宗门立身的剑，此刻握在他手里。
井底的黑暗深处，传来蒋阶的声音，不知从何处透上来，冷得像冰：“你以为拔了剑，就能斩断什么？”
沈言没答。他抬起手，用断剑的剑尖，指向井底。
剑尖颤了一下。不是他在抖，是剑在抖。
然后他转身，一步一步，走向石阶。断剑拖在地上，刮擦着岩石，发出刺耳的声响。
他得回广场。赵执事那边成与不成，他都得回去。锁魂符在阁楼，祭剑阵的反噬会先冲蒋阶。但蒋阶不会坐以待毙。
柴饦门的控制，系于这柄剑。剑在他手，门主便不再是门主。
他从被收留的杂役，变成了握着剑的人。
广场方向的崩塌声更近了。沈言爬上石阶，每一步都牵动肋骨的剧痛。他攥紧剑柄，锈蚀的铁刺破掌心，血渗进布条，把那“柴饦门”三个字染得更深。
断剑很重。比他想象的重。
像一整个宗门的债。
